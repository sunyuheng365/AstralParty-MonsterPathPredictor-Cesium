# MonsterPathPredictor（怪物寻路预测）

面向《吉星派对》（Astral Party）**CesiumLoader / AstralParty.Toys** 生态的纯只读 PVE 蹲怪辅助模组。

## 核心效果

- **点击怪物模型任意处常驻锁定跟踪（支持叠怪区分与拖图不丢锁）**：直接读取每个怪物渲染精灵（`SpriteRenderer`）的真实 3D 包围盒投影，点击头、身体、翅膀或脚底任意位置即可常驻锁定跟踪该怪物（自由拖动地图、点击空白处、出牌或触发战斗弹窗均不会丢失锁定），直到你**再次点击同一只怪物 / 点击切换到其他怪物 / 该怪物死亡**（或按 `Escape`）为止；多只怪物堆叠在同一地块时，会按实际偏移后的模型中心与镜头前后遮挡关系准确识别点击目标。
- **热键弹窗（默认 `F10`）— 行动序选怪 / 虚拟走位沙盒 / 局内路线样式自定义**：
  - 按 **`F10`**（可在配置中自定义 `pickerHotkey`，旧版默认 `F8` 升级时自动迁移为 `F10`）打开可拖拽的三标签控制面板；
  - **怪物列表（严格按真实行动顺序排序）**：依据回放 100% 实测的服务端顺序（`行动中 → 本轮未动按 (ActionWeight 升序, 生成序号 升序) → 本轮已动`，兼容 ID 绕回 `100,000 → 1` 与回合中刷怪），带 `#1 / #2` 行动序位与 `行动中 / 已动` 标识，点击即可快速锁定切换；
  - **虚拟走位沙盒（推演走位后怪物转向）**：可在面板中选中 `P1–P4`（默认本地玩家），通过**一键相邻格移位**或开启**「右键点击棋盘任意格移位」**将角色虚拟摆放到候选目标格（完全不影响实战走位，棋盘会显示紫色虚影与实位→虚位连线），随后直接点击任意怪物即可实时查看走位后怪物在岔路口会如何转向；支持单步撤回、单人重置与一键全部还原；
  - **局内自定义路线样式**：无需切出修改文件，局内实时调节**线条宽度、虚线行进速度、虚线长度、间距、标签字号、战后续行模式、步数/依据/100% 开关**，并可分别自定义 **主路线 / 高概率 / 低概率 / 战后续行 / 红箭 / 蓝箭** 6 类配色（支持 8 套预设色板 + RGBA 通道微调 + 一键恢复默认），改动自动持久化写入 `config.json`。
- **动态流动虚线与正计数步数标号（`0 → X` 格）**：从怪物当前位置与朝向出发，以**缓慢向前流动的动态虚线**延伸 **`X` 格**（`previewSteps` 默认 `12` 格，范围 `1–30`，支持热重载与弹窗实时调节），并沿路每格以**正计数**标注步数（怪物起点 **`0`**，依次 **`1, 2, …`** 递增至终点 **`12格`**，支持配置项 `showStepNumbers` 开关）；岔路口标签清晰区分步数与到目标玩家的距离（如 `追P3·距9`），不再与步数混淆。
- **岔路口方向与概率展示**：
  - 岔路口起步 / 战后续走：按攻略一致的 **红箭 / 蓝箭** 配色标注方向与依据；
  - 半路遇岔多分支可能：同时延伸所有分支的动态虚线，并在各岔路出口展示**精确概率百分比**（如 `62.5%` / `37.5%`、`50%` / `50%`）；
  - 遭遇玩家交战提示：在路径经过存活玩家的地块上标出 **`⚔遇P1`** 交战节点，并将交战后的续行虚线自动切换为更柔和的半透明样式（支持配置 `postCombatMode`：`continue` / `stop` / `redBlue`）。
- **纯只读安全**：仅声明 `ReadGameState` 权限，不发送任何操作指令，不篡改游戏逻辑。

## 实现的怪物寻路规则

以 B 站大数据回放实测（`BV1Kxsq67E9C`）及 UP 主置顶全图一图流攻略为准：

1. **全图自适应红蓝优先级**：直接读取 `LandManager` 原始 `neighborLandIds` 邻接表顺序（`红 ＞ 蓝 ＞ 无`），零地图硬编码，天然兼容全部 PVE 地图。
2. **岔路口起步 / 出生 / 战后续走**：
   - **优先读取怪物当前朝向（`Character.GetFrontNodeIds()` / `FrontIds` / `FrontNodeIds`）**：当怪物出生在岔路口或停靠在岔路口且仅有一个明确朝向箭头时，直接严格沿当前朝向行进，不盲目套用地图红蓝标；
   - 当怪物存在多个可选前进箭头（停靠岔路双出口或岔路战后续走）时，在当前合法前进方向集合内按「有红走红、无红走蓝」走。
3. **半路遇到岔路口（排队 + 最短路抽签）**：
   - 依据实测规则「**之后再遇岔，看当时站位**」：计算到所有存活且可追踪玩家的全图最短路距离（**回头方向也算、不限距离**）；
   - 按距离由近到远排队，**同距按座次 `P1 → P4` 优先**；
   - 对排到的玩家在所有等长最短路里等概率抽签（每条最短路 = 1 支签）；
   - 抽到掉头则跳过并将该部分概率顺延给下一个人；全员掉头兜底则两个前进方向各 `50%`。
4. **特殊状态、非主动怪与地图专属怪物机制**：
   - **嘲讽（Buff `10011`）**：支持识别嘲讽目标，允许掉头或改向沿最短路直奔嘲讽者（不受 `1067`/`1068` 罪证过滤限制）；
   - **小偷（`Thief`）**：回合起步同样响应嘲讽，但半路遇岔时无视嘲讽、按最近玩家寻路；当经过站在岔路口且持有星币（`Gold > 0`）的玩家时触发偷窃停顿并按红蓝优先级离开该岔路，若对方为 `0` 星币则不触发偷窃、继续沿原索敌方向前进；
   - **魔法学院（`82012`）学院安全官（`1018`）**：识别【问题学生】标记（Buff `2101001`）与服务端锁定 `BossTargetId`，回合起步新锁标记优先于嘲讽，半路遇岔则嘲讽优先于 `BossTargetId`；仅在与持有有效标记的目标交战后清除锁定，支持魔法学院动态版图切换（`cmd=1086`）；
   - **异变图书馆（`82016`）典狱长（`1067`）& 看守（`1068`）**：典狱长「真凶揭露」前与看守累计受伤未满 5 点（无 Buff `10681202`）前，仅对持有罪证（`CrimeNum > 0`）的玩家索敌与触发交战（跳过 `0` 罪证玩家，嘲讽例外），且半路遇岔仅判定排名第一的罪证目标（位于背后或同格时均不顺延、前向均分）；触发揭露或满 5 伤后自动切回全员常规索敌；
   - **园林中庭（`82015`）铜盏鸳鸯（`1047`）**：识别鸳鸯标记（Buff `10470101`）与服务端 `BossTargetId`，回合起步新锁标记可覆盖朝向与嘲讽，半路遇岔（含先打未标记玩家后的续行岔路）若未被嘲讽仍可自由掉头追击锁定目标，直至与持有有效标记的目标交战后清除；
   - 支持追踪**垃圾箱（Z3000）**、**雪莉**、**玲玲**技能挪动怪物后的下一步走向规则。

## 真实回放自动化认证（119,517 场真实 PVE 对局 · 98.5 GiB · 2,697,233 次岔路决策）

仓库自带自动化并行流式回放认证工具 [`tools/ReplayCertifier`](tools/ReplayCertifier/) 与一键脚本 [`scripts/certify-replays.ps1`](scripts/certify-replays.ps1)，直接编译核心寻路引擎 [`Core/MonsterPathEngine.cs`](src/MonsterPathPredictor/Core/MonsterPathEngine.cs)，支持国服/国际服双官方 CDN 自动回退（`sereplaycn` / `sereplayjp`）、游戏/Toys 嵌套与平铺双缓存格式、以及全部官服 PVE 地图图结构（含动态换图）。对 **119,517 场真实 PVE 对局**（覆盖全部 9 张公开回放 PVE 地图，共 `2,697,233 = 2,391,251 + 110,572 + 186,349 + 9,061` 次岔路决策）完成四道自动化门禁离线认证（耗时 `515.3s`，`0` 缺图，`0` 截断/损坏，`0` 预测缺失，`0` 预测集外命中，`0` 非法移动边，`bucketSumOk = true`，**4/4 门禁全部 PASS，全部 2,501,823 次确定性岔路 `0` 偏差**）：

- **门禁 0 — 语料覆盖与流完整性**：`119,517 / 119,517`（`1003 → 1016` 顺序状态机与协议完整性 `100%`，缺预测 / 集外命中 / 玩家及全类型怪物非法边均为 `0`，各分桶 `Total == DetTotal + ProbTotal`）→ **PASS**
- **门禁 1 — 主动怪 100% 确定性准确率（要求 `≥ 99.80%`、`n ≥ 100`）：`2,391,251 / 2,391,251 = 100.0000%`（PASS）**
  - 95% Wilson 置信区间：`[99.9998%, 100.0000%]`（实测 `0` 偏差）
  - 出生岔路：`235,537 / 235,537`（`100.0000%`，另有 `146` 次多分支）
  - 停靠岔路起步：`281,616 / 281,616`（`100.0000%`，另有 `3,371` 次雪莉投掷等三向均分多分支）
  - 岔路战后续走：`258,647 / 258,647`（`100.0000%`）
  - 半路遇岔：`1,387,260 / 1,387,260`（`100.0000%`，另有 `139,209` 次多分支）
  - 普通格战后再遇岔：`228,191 / 228,191`（`100.0000%`，另有 `43,623` 次多分支）
- **门禁 2 — 小偷（非主动怪）准确率（要求 `≥ 99.50%`、`n ≥ 10`）：确定性 `110,572 / 110,572 = 100.0000%` + 多分支 `9,061` 次（集外命中 `0`）→ PASS**
- **门禁 3 — 多分支概率与方向公平校准（`186,349` 次主动怪多分支岔路，`40` 个有效分档 `n ≥ 30`，要求各档 `|z| ≤ 3.0`）：最大 `|z| = 1.92`（PASS）**

  - `33.3%#1 / #2 / #3` 档（雪莉投掷等三向均分，三槽独立校准，`n = 3,322`）：实测 `33.53% / 33.26% / 33.20%`（`z = +0.25 / -0.09 / -0.16`）
  - `93.75% / 6.25%` 档（`n = 3,031`）：实测 `92.91% / 7.09%`（`z = ±1.92`）

### 一键复现自动化回放认证

```powershell
powershell -ExecutionPolicy Bypass -File scripts/certify-replays.ps1 `
  -ProtocolDir "<AstralParty.Toys>/src/AstralParty.Toys/Protocol" `
  -Maps "maps-3301.json,extra_pve_maps.json" `
  -CorpusFile "expanded-corpus-ids.txt" `
  -Concurrency 24
```

工具支持流式拉取（默认不落盘，也可通过 `-CacheDir` 直接扫描本地已保存的回放文件夹或叠加 `-SaveCache` 缓存），运行完毕自动导出 JSON + Markdown 认证报告并在任一门禁未通过时返回非零退出码。

## 安装方式（AstralParty.Toys）

1. 在 `AstralParty.Toys` 中确保已安装 **CesiumLoader**（SDK `>= 3.8.3`）。
2. 将打包好的 `MonsterPathPredictor-<version>.zip` 直接拖入 Toys 模组页导入，或手动解压至：
   ```text
   <游戏目录>/AstralParty_ModLoader/mods/MonsterPathPredictor/
   ├── MonsterPathPredictor.dll
   ├── MonsterPathPredictor.json
   └── config.json
   ```
3. 重启游戏生效。

## 配置项（`config.json`，支持热重载）

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 是否启用模组 |
| `previewSteps` | `12` | 向前延伸预测的格数 `X`（范围 `1–30`） |
| `dashLength` | `12.0` | 虚线单段长度（像素） |
| `gapLength` | `8.0` | 虚线间隔长度（像素） |
| `dashSpeed` | `26.0` | 动态虚线缓慢前行的速度（像素/秒，`0` 为静态） |

| `heightOffset` | `0.45` | 路线相对地块的 3D 高度偏移 |
| `fontSize` | `18` | 岔路口概率与标签字号 |
| `clickRadius` | `28.0` | 点击模型外缘时的容差半径（像素；点在模型内直接命中） |
| `clearOnEmptyClick` | `false` | 点击棋盘空白处是否取消锁定（默认 `false`：常驻跟踪，直到再点该怪/切怪/怪物死亡） |

## 本地开发与构建

### 运行单元测试（无需游戏 DLL）

```powershell
dotnet test tests/MonsterPathPredictor.Tests/MonsterPathPredictor.Tests.csproj -c Release
```

### 构建模组 DLL 并打包 ZIP

1. 将 `CesiumLoader.SDK.dll` 及游戏热更引用程序集（`AstralParty.Runtime.dll`、`UnityEngine.CoreModule.dll`、`UniTask.dll`、`Google.Protobuf.Runtime.dll`）放入项目根目录的 `refs/` 文件夹（已加入 `.gitignore`）。
2. 执行打包脚本：
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts/package.ps1
   ```
3. 输出包位于 `dist/MonsterPathPredictor-1.0.0.zip`，可直接导入 `AstralParty.Toys` 或提交到 `forge.hiynet.com`。
